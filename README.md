# IdleGrind releases

Installers for IdleGrind, a Windows app that runs your browser idle-game accounts in one window, within each game's rules.

This repo holds **installers only** (no source code). Installed copies of IdleGrind check it for updates.

Download the latest installer from [Releases](https://github.com/Hatsuyy/IdleGrind-releases/releases/latest).
